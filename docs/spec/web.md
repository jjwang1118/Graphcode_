# web 規格

給人看的網頁：2D 圖、細節、影響範圍。後端 `src/codegraph_fable/web/`，前端 `frontend/`。
測試：`tests/test_web.py`（視圖與 API）、`frontend/src/elements.test.ts`（資料轉換）。

**畫面本身沒有在瀏覽器裡驗證過**（這台機器沒有可用的無頭瀏覽器）。已驗證的只有：型別檢查、建置、資料轉換的測試、後端實際啟動後首頁與 API 有回應。

---

## 啟動

```bash
# 後端（同時提供建置好的前端）：http://127.0.0.1:8000
CODEGRAPH_ALLOWED_ROOTS=/path/to/projects python -m codegraph_fable.web [--port 8000] [--reload]
# --reload：後端程式碼一改就自動重啟（不含前端）

# 前端（在 frontend/ 底下）
npm install --legacy-peer-deps     # 第一次。npm 9.2 需要這個參數
npm run build                      # 產出 frontend/dist，後端會自動提供
npm run dev                        # 開發用：http://localhost:5173，/api 轉給 :8000
npm test                           # vitest
npx tsc -b                         # 型別檢查
```

| 環境變數 | 用途 |
|---|---|
| `CODEGRAPH_ALLOWED_ROOTS` | **必填**。允許分析的資料夾，多個用 `:` 分隔。沒設定＝所有路徑都拒絕 |
| `CODEGRAPH_FRONTEND_DIST` | 前端建置結果的位置；預設 `frontend/dist` |

Node 18、npm 9.2 可用；Vite 釘在 6.x（Vite 7 需要更新的 Node）。

## API

全部是 `POST`、JSON；錯誤回 `{ "detail": "…" }`。403＝路徑不被允許，404＝找不到專案或節點。

| 端點 | 輸入 | 輸出 |
|---|---|---|
| `GET /api/config` | — | `allowed_roots` |
| `/api/analyze` | `project`、`python?`、`force?` | `source` ＋ `meta` 的摘要欄位 |
| `/api/view` | `project`、`expanded[]`、`edge_types[]`、`externals` | `{ nodes, edges, meta }`（見下） |
| `/api/find` | `project`、`name` | 最多 50 筆：`id`、`type`、`label`、`line`、`signature`、`ancestors` |
| `/api/detail` | `project`、`target`（完整 id） | `query.detail` 的結果 |
| `/api/impact` | `project`、`target`、`depth?` ＋ `/api/view` 的參數 | `query.impact` 的結果 ＋ `visible` |
| `/api/overview` | `project` | `query.overview` 的結果 |

分析結果的取得與過期判斷與 MCP 共用（`service.py`，規則見 `mcp.md` MCP-2 – MCP-5）。

## 視圖（`query.view`）

畫面上的圖是整張圖的收合版，**由後端算**，前端只收集查詢條件。

| # | 規則 |
|---|---|
| W-V1 | **層級**（`level`）決定預設看多細：0＝只有專案根、n＝到第 n 層目錄、`null`＝不收合。API 沒給時是 1 |
| W-V2 | 使用者個別展開（`expanded`）或收合（`collapsed`）的節點疊在層級上：實際展開的＝層級 ∪ `expanded` − `collapsed` |
| W-V3 | 專案根永遠在畫面上。其他節點出現的條件：它的上層已展開 |
| W-V4 | **骨架線**：每個看得見的節點到它看得見的上一層，`contains`（資料夾、外部群組）或 `defines`（檔案、class、function）。一定畫，不受 `edge_types` 影響 |
| W-V5 | **關係線**（`imports`、`calls`、`inherits`、`references`，由 `edge_types` 篩選）：看不見的節點由最近一個看得見的上層代表，線接到代表節點上；同一對、同一種關係合成一條，`count` 是總數 |
| W-V6 | 不畫：兩端是同一個代表節點的關係線、上下層之間的關係線（已有骨架線） |
| W-V7 | 外部套件（`externals`）：`grouped`＝依類別合成虛擬節點 `extgroup:<類別>`，可展開；`full`＝每個套件一個節點；`hidden`＝不顯示 |
| W-V8 | `/api/impact` 的 `visible`：每個受影響節點在目前畫面上由誰代表（看不見為 null） |

節點欄位：`id`、`type`、`label`、`children`（下一層有幾個）、`expanded`、`parent?`、`line?`、`end_line?`、`signature?`、`category?`、`language?`、`parse_error?`、`installed?`、`unresolved_calls?`（這個節點自己有幾個呼叫解不出）。

線的欄位：`id`、`source`、`target`、`type`、`count`。

`/api/view` 與 `/api/impact` 的輸入多兩個欄位：`level`、`collapsed`。

## 前端

**版面、視覺、操作方式整體沿用參照專案 `codegraph/frontend`（D13）。** 新功能放進原本的框架裡，不另起一套。

| 檔案 | 職責 | 對應參照專案 |
|---|---|---|
| `src/api.ts` | API 的型別與呼叫。**改後端回傳的形狀要同步改這裡** | `api/` |
| `src/elements.ts` | API 資料 → Cytoscape 的 element；影響範圍怎麼亮（`toWave`） | `graph/transform.ts` |
| `src/palette.ts`、`src/graphStyle.ts` | 配色、畫布與縮圖的樣式 | `graph/style.ts` |
| `src/Graph.tsx` | 畫布。只有這裡碰 Cytoscape | `components/GraphCanvas.tsx` |
| `src/Graph3D.tsx` | 3D 畫布。只有這裡碰 three.js | `components/Graph3D.tsx` |
| `src/DetailBox.tsx` | 右側欄的內容（節點的細節與影響範圍、線的關係） | 無（參照專案是浮動小視窗） |
| `src/Sidebar.tsx` | 側欄 | `components/Sidebar.tsx` |
| `src/App.tsx` | 狀態、搜尋列、版面 | `App.tsx` |
| `src/style.css` | 版面與背景動態 | `index.css` |

### 沿用的部分

| 項目 | 內容 |
|---|---|
| 版面 | 左側欄 260px（`CODEGRAPH`、專案路徑、畫布、層級、圖例、統計）＋ 上方圓角搜尋列 ＋ 畫布（＋ 右側欄，見 W-F2） |
| 視覺 | 深色、等寬字；型別決定形狀與顏色（repo 六角形、directory 圓角方形、file 圓、class 五邊形、function 三角形、external 菱形）；標籤在節點右側；線的粗細分段表示筆數；背景格線／光暈／掃描線 |
| 滑過節點 | 鄰居亮起，其餘變暗 |
| 點節點 | 影響範圍一層一層亮起（每層間隔 300 毫秒）；點空白處還原 |
| 點線 | 顯示這條線代表的關係（在右側欄，見 W-F2） |
| 搜尋 | 邊打字邊比對畫面上的節點名稱，符合的發亮並置中，其餘變暗 |
| 其他 | 左下縮放鈕（＋ － ⤢）、右下縮圖（可點擊移動）、層級下拉選單、外部套件三種模式 |
| 呼叫線 | 平常不畫，看影響範圍時才出現 |

### 新增的部分（參照專案沒有）

| # | 規則 |
|---|---|
| W-F1 | **雙擊節點**展開或收合它（疊在層級之上；換層級會清掉）。可展開的節點有亮色邊框 |
| W-F2 | **右側欄**（360px）：點節點或線才出現，點空白處或 × 收起。**不用浮動小視窗**（使用者要求，2026-11-15；這一點與參照專案不同）。節點的內容：簽名、影響範圍摘要與各層、呼叫、引用、狀態、副作用、例外、原始碼；空的區塊不顯示。欄位出現或收起時畫布會跟著調整寬度 |
| W-F3 | **影響範圍分三種邊框**：確定實線、可能虛線、候選紫色點線；起點最粗。標在代表節點上，一個節點取最早的一步、最強的一種 |
| W-F4 | **可靠度照實顯示**：細節每區有「準確／推論／估計」小標籤；有呼叫解不出的節點是紅色虛線框；影響範圍摘要帶「專案內解不出的呼叫數」 |
| W-F5 | **圖例的關係線可以點**：開關 `imports`／`inherits`／`calls`／`references`。預設只開前兩個 |
| W-F6 | 搜尋列按 **Enter**：找收合中、畫面上看不到的定義，點結果會展開它的上層 |
| W-F7 | 線依關係上色：`imports` 藍、`inherits` 粉、`calls` 青綠、`references` 土黃；骨架 `contains` 綠、`defines` 紫灰 |
| W-F18 | **右側欄的排版**（使用者要求不要雜）：最上面是名稱、型別與行號、簽名、說明第一行（最多兩行）。其下每一類一個**可收合的區塊**，標題列有筆數與可靠度標籤。區塊內再分小組（影響範圍的每一層、呼叫的專案內／解不出／外部）。清單**一筆一行**，左邊名稱太長就省略、右邊是行號或關係；每個清單最高約 230px，超過在清單內捲動。預設展開：影響範圍（只開第 1 層）、呼叫（外部收合）、狀態、副作用、例外；預設收合：引用、超過 25 行的原始碼。副作用與例外用小標籤呈現 |

### 3D（T8）

與 2D 吃同一份視圖、同一個影響範圍、同一個細節框與側欄設定（D5），差別只在呈現。

| 項目 | 2D | 3D |
|---|---|---|
| 排版 | `cose`，排完固定 | three.js 的力導向，持續模擬 |
| 節點間距 | 排完後縮放座標 | 改力導向的理想邊長（24 × 倍率）後重新加熱 |
| 節點大小 | 換樣式表 | 換球體半徑與標籤高度 |
| 影響範圍 | 邊框分三種 | 沒有邊框，改用顏色：起點白、確定青綠、可能半透明青綠、候選紫；其餘變暗 |
| 有解不出／語法錯誤 | 紅色虛線框 | 節點變紅 |
| 展開或收合 | 雙擊 | 350 毫秒內點同一個節點兩次（函式庫沒有雙擊事件） |
| 換圖 | 節點滑到新位置 | 沿用舊節點物件所以位置不動，新節點從上層的位置長出來 |
| 動態 | 漂浮、流動的虛線 | 關係線上有往箭頭方向流動的光點（線超過 800 條不放） |
| 搜尋發亮、縮圖、縮放鈕 | 有 | 沒有（滑鼠拖曳旋轉、滾輪縮放） |

`calls` 與 `references` 的線在 3D 不參與拉力：它們只在看影響範圍時出現，不能讓圖因此變形。

### 共通規則

| # | 規則 |
|---|---|
| W-F8 | 前端不做圖的運算（收合、加總、影響範圍都在後端）。條件一變就重新要一次視圖 |
| W-F9 | Cytoscape 實例放在 ref，不進 React state |
| W-F10 | **排版只有力導向**（`cose`，D8）。節點有增減才重排：舊節點留在原位，新節點從上層的位置長出來 |
| W-F11 | **文字從簡**（D13）：畫面上只放名稱、數字、短標籤；說明收進滑鼠提示（`title`）。統計的警示列只在不是 0 時出現 |
| W-F12 | 清單超過上限要寫出總數 |
| W-F13 | 2D／3D 由側欄切換。兩個畫布都常駐、只切可見性（卸載重建會丟掉位置）；3D 第一次切過去才載入（three.js 另成一個檔） |
| W-F14 | **節點間距**：側欄的滑桿（0.8–6，預設 2.5，記在瀏覽器裡）。排版只決定相對位置，排完後以圖的中心為準把座標乘上倍率；拖滑桿只做幾何縮放、不重排（沿用參照專案的做法） |
| W-F15 | **節點大小**：側欄的滑桿（1–5，預設 2，記在瀏覽器裡）。形狀與字一起放大（字放大得慢一點）；只換樣式，位置不動。邊框與線的粗細不跟著變 |
| W-F16 | **動態**（側欄開關，預設開，記在瀏覽器裡）：① 節點以各自的相位緩緩漂浮（幅度 5、約 25 fps）② 關係線是往箭頭方向流動的虛線，骨架線不動 ③ 展開、收合、換層級時節點從舊位置滑到新位置（650 毫秒），新節點從上層長出來。節點超過 500 個不漂浮、關係線超過 800 條不流動；分頁在背景時暫停 |
| W-F17 | 漂浮只影響畫面：節點「真正的位置」另外記著，排版、間距、縮圖、下次重排都用真正的位置。拖節點時它不漂浮，放開處成為新的真正位置 |

## 已知限制

| 限制 | 說明 |
|---|---|
| 沒有在瀏覽器裡看過 | 排版好不好看、互動順不順都未驗證 |
| 節點很多時 | 全部展開大專案會有上千個節點，`cose` 會慢且擠。靠「預設收合」避免，沒有另外的保護 |
| 展開後整張圖會重排 | 舊節點從原位置出發，但仍可能移動 |
| 點節點會同時查影響範圍與細節 | 大專案上每次點擊要等後端算完 |
| 3D 完全沒有測試 | 需要 WebGL；只確認了型別檢查與建置 |
| 前端 JS 體積 | 主檔約 710 kB、3D 另一個檔約 1.5 MB（第一次切到 3D 才載入） |

沒有測試的：`Graph3D.tsx`、`Graph.tsx`、`DetailBox.tsx`、`Sidebar.tsx`、`App.tsx`（需要瀏覽器環境）、`/api/config`、`python` 參數。
